Recap:
Machines in the game have the ability to be underclocked by any percent, and overclocked up to 50% for every power shard inserted into the machine, with a limit to 3, meaning any machine can run from at any rate between 0% and 250% of it's normal speed, decreasing or increasing the time it takes to complete a task as well as the inputs and outputs of items per minute listed on the machine's UI, but also the power requirements, allowing you to create any number of items per minute that you need.
